# 快速上手

## 一次生成完整的流程

1. **输入文字** —— 在「文字与公式」里输入，或用「导入文档」上传正文。LaTeX 先用「转换 LaTeX」转写。
2. **选字体** —— 在「笔迹与纸张」选择服务端字体，或上传自己的字体；界面字体不影响纸张字体。
3. **定纸张** —— 要么给出宽度和高度（会自动生成带横线的稿纸），要么上传一张背景图片。
4. **调参数** —— 想省事就用默认值；要细调看[参数详解](parameters.md)。
5. **点「生成预览」** —— 「手写预览」显示结果；勾选「预览全部页面」后可翻页检查。
6. **导出** —— 预览区的「ZIP」导出整页 PNG 压缩包，「PDF」导出合并文档。

!!! tip "先预览再导出"
    默认预览只渲染第一页；需要检查整篇时勾选「预览全部页面」。ZIP 和 PDF 导出均处理全部页面。

## 界面是三个区

宽屏工作台包含三个区，窄屏时自动重排：

- **文字与公式** —— 正文、文档导入、LaTeX / Markdown 转换、书信排版和插图。
- **手写预览** —— 预览、翻页、缩放与导出。
- **笔迹与纸张** —— 字体、纸张尺寸、边距、手写自然度、涂改效果和预设。

详细参数按组折叠，展开所需部分即可。

## 界面外观

打开「外观与设置」可选择预设主题色，或用色盘、六位 HEX 色值自定义，并可恢复默认绿色。主题色保存在本机，刷新后保持；只影响应用界面，不改变纸张字体、墨色或导出图片。

手机不显示顶部品牌栏，设置入口位于工作台上方的紧凑操作行；语言、明暗切换、使用指南和开源链接也可在设置中访问。桌面保留顶部导航。

## 输入文字

!!! warning "`.doc` 不支持"
    上传文档的格式是 `.docx`、`.pdf`、`.txt`、`.rtf`。老式的 `.doc` 虽然出现在文件选择框里，
    但服务端不认识它，会返回「doc文件暂不支持」。请先另存为 `.docx`。

- 正文、设置及上传资源会保存到本机；留意界面的保存状态。清理站点数据或存储失败会影响恢复。
- 上传文档只是把正文**填进文字框**，填完之后仍然可以手动编辑。
- Markdown 清洗默认将表格转换为 LaTeX 方格表，也可在表格菜单中选择原有文本模式；随后点击 LaTeX 转换并生成预览。表格绘制完整外框与各行列格线，格线统一粗细，单元格内容按墨迹居中。
- Markdown 清洗保留公式源码；使用 LaTeX 转换按钮转写公式。带明确横竖分隔线的 `array`、分布律和增广矩阵保留为可编辑的结构文本，生成时按二维单元格布局绘制，继承所选手写字体和墨色。过宽表格整体缩小，分页不拆散单元格；不支持的语法保留原文。
- 本 fork 没有固定的 10 页截断；长文本仍受机器资源及[服务端限制](../self-hosting/fonts-and-limits.md)影响。

## 选字体

两种方式二选一：

- **用服务器已有的字体** —— 在下拉框里选。这些是部署时放进 `ttf_files/` 的字体。
- **上传自己的字体** —— 点「上传字体」选择 `.ttf`、`.otf` 或 `.ttc`；上传后自动选中。切换到服务端字体后按该选择渲染。

## 定纸张

宽度和高度、背景图片这两组是**互斥**的：

- 给了宽度和高度 → 后端生成一张白底带横线的稿纸（要不要横线由「增加下划线」决定）。
- 上传了背景图片 → 用你的图当底，此时宽度和高度会置灰。

上传背景图片后会弹窗问你要不要自动检测边距 —— 选「是」的话，程序会分析图片里的横线，
把上/下/左/右边距和行间距自动填好。自己画的横线稿纸用这个功能很省事。

## 记住你的参数

设置面板中的按钮管理本机参数快照：

- **保存设置** —— 把当前所有参数存下来。
- **载入设置** —— 把存过的参数读回来。
- **恢复默认** —— 恢复默认值。

预设下拉框还提供「小字横线 · 云烟体」「自然手写」「工整笔迹」。纸张预设需要先移除背景；
云烟体预设优先使用对应字体，未安装时保留当前字体。草稿和预设的存储边界见[架构说明](../architecture.md)。

## 排队与等待

后端同一时间只处理有限个任务。人多了会看到：

- 工作台显示任务状态，预览区显示生成进度。
- 队列已满时显示重试倒计时，提交按钮会暂时禁用。

生成中的进度通过 WebSocket 实时推给你；连接不上时自动退回轮询，界面上没有区别。
