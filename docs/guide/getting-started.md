# 快速上手

## 一次生成完整的流程

1. **输入文字** —— 在「文字与公式」里输入，或用「导入文档」上传正文。LaTeX 先用「转换 LaTeX」转写。
2. **选字体** —— 在「笔迹与纸张」选择服务端字体，或上传自己的字体；界面字体不影响纸张字体。
3. **定纸张** —— 要么给出宽度和高度（会自动生成带横线的稿纸），要么上传一张背景图片。
4. **调参数** —— 想省事就用默认值；要细调看[参数详解](parameters.md)。
5. **点「生成预览」** —— 「手写预览」显示结果；勾选「预览全部页面」后可翻页检查。
6. **导出** —— 预览区的「ZIP」导出整页 PNG 压缩包，「PDF」导出合并文档。

!!! tip "先预览再导出"
    默认预览只渲染第一页；需要检查整篇时勾选「预览全部页面」。ZIP 和 PDF 导出均处理全部页面。

## 界面是三个区

宽屏工作台包含三个区，窄屏时自动重排：

- **文字与公式** —— 正文、文档导入、LaTeX / Markdown 转换、书信排版和插图。
- **手写预览** —— 预览、翻页、缩放与导出。
- **笔迹与纸张** —— 字体、纸张尺寸、边距、手写自然度、涂改效果和预设。

详细参数按组折叠，展开所需部分即可。

## 界面外观

打开「外观与设置」可选择预设主题色，或用色盘、六位 HEX 色值自定义，并可恢复默认绿色。主题色保存在本机，刷新后保持；只影响应用界面，不改变纸张字体、墨色或导出图片。

手机不显示顶部品牌栏，设置入口位于工作台上方的紧凑操作行；语言、明暗切换、使用指南和开源链接也可在设置中访问。桌面保留顶部导航。

## 输入文字

!!! warning "`.doc` 不支持"
    上传文档的格式是 `.docx`、`.pdf`、`.txt`、`.rtf`。老式的 `.doc` 虽然出现在文件选择框里，
    但服务端不认识它，会返回「doc文件暂不支持」。请先另存为 `.docx`。

- 正文、设置及上传资源会保存到本机；留意界面的保存状态。清理站点数据或存储失败会影响恢复。
- 上传文档只是把正文**填进文字框**，填完之后仍然可以手动编辑。
- Markdown 清洗默认将表格转换为 LaTeX 方格表，也可在表格菜单中选择原有文本模式；点击「整理文本」完成清洗与公式转写，再生成预览。表格绘制完整外框与各行列格线，格线统一粗细，单元格内容按墨迹居中。
- 「整理文本」固定先清理 Markdown，再转写公式；代码片段保留内容，可用「撤销整理」恢复原文。带明确横竖分隔线的 `array`、分布律和增广矩阵保留为可编辑的结构文本，生成时按二维单元格布局绘制，继承所选手写字体和墨色。过宽表格整体缩小，分页不拆散单元格；不支持的语法保留原文。
- 本 fork 没有固定的 10 页截断；长文本仍受机器资源及[服务端限制](../self-hosting/fonts-and-limits.md)影响。

## 理工作业与公式

点击「整理文本」，再生成预览。矩阵、行列式与分段函数按二维排列；分段条件左对齐，括号随内容高度伸缩。表格内的单位、希腊字母和分式使用同一套字形回退与排版。

常用工程输入如 `\mathcal{L}`、`\oiint`、`\SI{4.7}{\kilo\ohm}`、`\si{\metre\per\second\squared}` 和 `\num{1.2e-3}` 可以转写。带自定义选项、宏定义或不能可靠解析的表达式会保留源码，请先检查预览。

程序示例的代码围栏和反引号会被去掉，内部的指针、下划线、比较符和缩进保留。清洗是一次文本转换；去掉代码边界后，再次清洗或公式转换不能识别原先的代码身份。

常见 CircuiTikZ 电路可以直接粘贴到正文并生成预览；清洗和公式转换保留电路源码，生成时绘制接线与手写标注。例如：

```tex
\begin{circuitikz}
\draw (0,0) to[V,l=$U_s$] (0,3)
  to[R,l=$R$] (4,3) to[C,l=$C$] (4,0)
  -- (0,0) node[ground]{};
\end{circuitikz}
```

支持电阻、电容、电感、电压源、电流源、正弦源、电池、二极管、LED、开关、短路和开路支路，以及接点、端子、接地与名称标注。可使用绝对坐标、`+` / `++` 相对坐标、`\coordinate` 命名坐标、`--` / `|-` / `-|` 连线和 `cycle` 闭合；`[american]` 使用锯齿电阻。电压和电流标注可用显式方向，如 `i>^=$i$`；省略方向的 `i/v` 需要在环境中明确 `[RPvoltages]`，避免隐含方向约定改变含义。

电路整体缩放与分页，接线不单独抖动；标签继承所选字体。Panache 不运行完整 TeX／TikZ：运放、晶体管、宏定义、自定义样式和未支持的命令会使整段电路保留为源码。复杂图形可先导出图片，再通过「插入图片」加入正文。检查排版时建议使用霞鹜文楷和「工整笔迹」预设。

## 常见课程宏写法

公式转换支持以下常见写法，不需要粘贴 `\usepackage`：

- `amsmath`：分式、矩阵、分段函数与 `alignat` 多行推导。
- `siunitx`：`\SI{4.7}{\kilo\ohm}`、`\qty{9.81}{\metre\per\second\squared}` 与 `\unit{\volt}`。
- `mhchem`：`\ce{(NH4)2SO4 -> 2NH4+ + SO4^2-}`、反应箭头、物态和结晶水；离子电荷与原子个数分别排版。
- `physics`：`\dv{x}{t}`、`\dv[2]{x}{t}`、`\pdv{f}{x}`、`\abs{x}` 与 `\norm{\mathbf v}`。

这是常见命令的转写兼容，不加载完整宏包。自定义宏、复杂化学结构和暂不支持的参数会保留原文；生成前请检查预览。

## 选字体

两种方式二选一：

- **用服务器已有的字体** —— 在下拉框里选。这些是部署时放进 `ttf_files/` 的字体。
- **上传自己的字体** —— 点「上传字体」选择 `.ttf`、`.otf` 或 `.ttc`；上传后自动选中。切换到服务端字体后按该选择渲染。

## 定纸张

宽度和高度、背景图片这两组是**互斥**的：

- 给了宽度和高度 → 后端生成一张白底带横线的稿纸（要不要横线由「增加下划线」决定）。
- 上传了背景图片 → 用你的图当底，此时宽度和高度会置灰。

上传背景图片后会弹窗问你要不要自动检测边距 —— 选「是」的话，程序会分析图片里的横线，
把上/下/左/右边距和行间距自动填好。自己画的横线稿纸用这个功能很省事。

## 记住你的参数

设置面板中的按钮管理本机参数快照：

- **保存设置** —— 把当前所有参数存下来。
- **载入设置** —— 把存过的参数读回来。
- **恢复默认** —— 恢复默认值。

预设下拉框还提供「小字横线 · 云烟体」「自然手写」「工整笔迹」。纸张预设需要先移除背景；
云烟体预设优先使用对应字体，未安装时保留当前字体。草稿和预设的存储边界见[架构说明](../architecture.md)。

## 排队与等待

后端同一时间只处理有限个任务。人多了会看到：

- 工作台显示任务状态，预览区显示生成进度。
- 队列已满时显示重试倒计时，提交按钮会暂时禁用。

生成中的进度通过 WebSocket 实时推给你；连接不上时自动退回轮询，界面上没有区别。


## 检查应用更新

开启自动检查后，发现新版本会弹出更新窗口，直接显示版本和更新要点，可选择「立即更新」或「稍后再说」。同一版本本次打开只自动提醒一次；生成中会等任务结束再提醒。也可在「外观与设置 → 应用更新」中手动检查并再次打开更新窗口。桌面客户端会选择当前系统、架构和安装类型对应的官方包，显示更新说明和下载进度；下载可取消，校验通过后才提供打开入口。Windows 安装版打开安装程序，便携版定位文件后手动替换；macOS 下载 DMG 后按系统流程安装。

Web / PWA 的「检查更新」检查当前网站的部署，并在草稿保存成功后刷新。正在生成时需先完成或取消任务；网站服务升级由部署管理员处理，不把 GitHub 桌面客户端新版本当成网站已升级。安装包尚未上传、架构不支持或 GitHub 不可达时，界面会说明原因并提供重试或官方发布页入口。
