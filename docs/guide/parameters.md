# 参数详解

参数位于「笔迹与纸张」面板，分为基本设置、纸张设置、手写自然度和涂改效果。
下列为默认配置；本机已恢复的草稿或预设可能采用其他值，以当前输入框为准。

!!! info "扰动是什么"
    手写之所以像手写，是因为每个字都略有不同。后端用正态分布给每个字加一点随机偏移，
    参数里的「标准差」就是控制这个分布宽度的 —— **值越大越潦草，0 就是完全规整**。
    默认值已经调得比较自然，不建议一上来就大改。

## 基本参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 字体大小 | `160` | 每个字的字号（像素）。字越大，同样纸张能放的字越少。 |
| 行间距 | `260` | 两行之间的基线距离。要保证大于字体大小，否则会叠字。 |
| 上边距 | `50` | 正文距纸张上边缘的距离。 |
| 下边距 | `50` | 正文距纸张下边缘的距离。 |
| 左边距 | `50` | 正文距纸张左边缘的距离。 |
| 右边距 | `50` | 正文距纸张右边缘的距离；`>>>` 右对齐也以这条边为基准。 |
| 字间距 | `1` | 字与字之间的额外间隙。 |
| 宽度 | `2800` | 纸张宽度。与背景图片互斥。 |
| 高度 | `3960` | 纸张高度。与背景图片互斥。 |

默认纸张约为 A4 比例，像素尺寸并不规定打印 DPI。

## 开关

| 参数 | 默认值 | 说明 |
|---|---|---|
| 添加横线 | 开 | 在每一行下方画一条横线。自动生成的稿纸也靠它决定要不要画线。 |
| 加宽英文词间距 | 关 | 英文单词之间留更宽的间隙，避免挤在一起。中文排版用不上。 |

## 手写自然度

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 行间距扰动 | `0` | 每行行距的浮动。默认完全不浮动。 |
| 字体大小扰动 | `2` | 每个字大小的浮动。 |
| 字间距扰动 | `2` | 每个字之间间隙的浮动。 |
| 笔画横向偏移 | `3` | 每个字左右位置的浮动。 |
| 笔画纵向偏移 | `3` | 每个字上下位置的浮动。 |
| 笔画旋转偏移 | `0.05` | 每个字的旋转角度浮动，单位是弧度。 |
| 墨汁深度标准差 | `30` | 笔画墨色的深浅浮动，模拟用笔轻重的变化。 |

## 涂改痕迹

想在纸上留点「写错划掉」的痕迹时用这一组。

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 涂改出现的几率 | `0.005` | 每个字被划掉的概率。 |
| 涂改线宽度 | `8` | 划线的粗细。 |
| 涂改线长度的标准差 | `2` | 划线长度的浮动。 |
| 涂改线宽度的标准差 | `2` | 划线粗细的浮动。 |
| 涂改线角度的标准差 | `2` | 划线倾斜角度的浮动。 |

## 内置预设

设置面板的预设下拉框提供「小字横线 · 云烟体」「自然手写」「工整笔迹」。

**小字加下划线（云烟体）** —— 用云烟体、小字号、宽行距、四边留白很大，配下划线：

| 参数 | 预设值 | （对比默认值） |
|---|---:|---|
| 字体大小 | `70` | 160 |
| 行间距 | `100` | 260 |
| 上/下/左/右边距 | `150` | 50 |
| 字体大小扰动 | `1` | 2 |
| 行间距扰动 | `1` | 0 |
| 字间距 | `2` | 1 |
| 笔画横向偏移 | `1` | 3 |
| 笔画纵向偏移 | `1` | 3 |
| 涂改出现的几率 | `0` | 0.005 |
| 增加下划线 | 开 | 开 |

应用纸张预设前需先移除背景图片。云烟体预设会选择可用的 `云烟体.ttf`；
该字体未安装时保留当前选择的字体。

## 调参建议

- **字挤在一起** → 加大「行间距」或「字间距」。
- **看起来太整齐、不像手写** → 适当加大「笔画横向偏移」「笔画纵向偏移」。
- **看起来太乱** → 先把「笔画旋转偏移」降下来，它对观感影响最大。
- **想每页容纳更多字** → 减小「字体大小」「行间距」或边距。
- **改了参数没效果** → 确认改完后重新点了「生成预览」；界面上的改动不会自动重新渲染。
