# 参数详解

参数位于「笔迹与纸张」面板，分为基本设置、纸张设置、手写自然度和涂改效果。
下列为默认配置；本机已恢复的草稿或预设可能采用其他值，以当前输入框为准。

!!! info "扰动是什么"
    手写之所以像手写，是因为每个字都略有不同。后端用正态分布给每个字加一点随机偏移，
    参数里的「标准差」就是控制这个分布宽度的 —— **值越大越潦草，0 就是完全规整**。
    默认值已经调得比较自然，不建议一上来就大改。

## 基本参数

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 字体大小 | `160` | 每个字的字号（像素）。字越大，同样纸张能放的字越少。 |
| 行间距 | `260` | 两行之间的基线距离。要保证大于字体大小，否则会叠字。 |
| 上边距 | `50` | 正文距纸张上边缘的距离。 |
| 下边距 | `50` | 正文距纸张下边缘的距离。 |
| 左边距 | `50` | 正文距纸张左边缘的距离。 |
| 右边距 | `50` | 正文距纸张右边缘的距离；`>>>` 右对齐也以这条边为基准。 |
| 字间距 | `1` | 字与字之间的额外间隙。 |
| 宽度 | `2800` | 纸张宽度。与背景图片互斥。 |
| 高度 | `3960` | 纸张高度。与背景图片互斥。 |

默认纸张约为 A4 比例，像素尺寸并不规定打印 DPI。

## 开关

| 参数 | 默认值 | 说明 |
|---|---|---|
| 添加横线 | 开 | 在每一行下方画一条横线。自动生成的稿纸也靠它决定要不要画线。 |
| 加宽英文词间距 | 关 | 英文单词之间留更宽的间隙，避免挤在一起。中文排版用不上。 |

## 手写自然度

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 行间距扰动 | `0` | 每行行距的浮动。默认完全不浮动。 |
| 字体大小扰动 | `2` | 每个字大小的浮动。 |
| 字间距扰动 | `2` | 每个字之间间隙的浮动。 |
| 笔画横向偏移 | `3` | 每个字左右位置的浮动。 |
| 笔画纵向偏移 | `3` | 每个字上下位置的浮动。 |
| 笔画旋转偏移 | `0.05` | 每个字的旋转角度浮动，单位是弧度。 |
| 墨汁深度标准差 | `30` | 笔画墨色的深浅浮动，模拟用笔轻重的变化。 |

## 涂改痕迹

想在纸上留点「写错划掉」的痕迹时用这一组。

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 涂改出现的几率 | `0.005` | 每个字被划掉的概率。 |
| 涂改线宽度 | `8` | 划线的粗细。 |
| 涂改线长度的标准差 | `2` | 划线长度的浮动。 |
| 涂改线宽度的标准差 | `2` | 划线粗细的浮动。 |
| 涂改线角度的标准差 | `2` | 划线倾斜角度的浮动。 |

## 上传横线纸与自动对齐

在「纸张设置」上传背景后，选择「自动识别纸张」。应用会测量横线中心之间的行距，
校正可识别的倾斜，并同时更新背景和四周排版边距。背景文件名下的「重新识别纸张」
可再次执行；每次识别都使用当前背景，不会反复叠加旋转。

识别后的上边距用于让首行落在横线上，不等于图片顶部到第一条线的距离。
若第一条线太靠近纸边，会从下一条可完整容纳文字的横线开始。字号过大时会适当缩小，
其他字号保留。识别结果和校正后的背景会随草稿保存，复杂公式之后的文字也会恢复到横线网格。

空白、线条不足或间距不规则的图片会提示手动设置，并保留原参数。
识别过程中更换背景或修改参数后，旧结果不会覆盖新的设置。
请使用尽量平整、裁剪清晰的纸张；透视变形、弯曲纸张和大面积遮挡不属于自动旋转校正的范围。
完成后生成预览确认效果；需要更贴线时，可降低「行间距扰动」和「笔画纵向偏移」。

## 内置预设

「排版预设」可选择「标准排版」或「作业笔记」。作业笔记在现有边距内额外保留正文留白，
为编号条目和续行安排缩进，长公式尽量在关系符等适合的位置换行。已有横线的范围和对齐不变；
分式、上下标、表格和电路等整体内容保持完整，过宽内容仍受纸张尺寸限制。

切换只影响生成的版式，不会改写输入、重置字体或移除背景；支持上传并识别过的横线纸。
排版选择随草稿和保存的预设保留。选择「标准排版」即可恢复按当前边距生成，随后重新生成预览。

设置面板的预设下拉框提供「小字横线 · 云烟体」「自然手写」「工整笔迹」。

**小字加下划线（云烟体）** —— 用云烟体、小字号、宽行距、四边留白很大，配下划线：

| 参数 | 预设值 | （对比默认值） |
|---|---:|---|
| 字体大小 | `70` | 160 |
| 行间距 | `100` | 260 |
| 上/下/左/右边距 | `150` | 50 |
| 字体大小扰动 | `1` | 2 |
| 行间距扰动 | `1` | 0 |
| 字间距 | `2` | 1 |
| 笔画横向偏移 | `1` | 3 |
| 笔画纵向偏移 | `1` | 3 |
| 涂改出现的几率 | `0` | 0.005 |
| 增加下划线 | 开 | 开 |

应用纸张预设前需先移除背景图片。云烟体预设会选择可用的 `云烟体.ttf`；
该字体未安装时保留当前选择的字体。

## 调参建议

- **字挤在一起** → 加大「行间距」或「字间距」。
- **看起来太整齐、不像手写** → 适当加大「笔画横向偏移」「笔画纵向偏移」。
- **看起来太乱** → 先把「笔画旋转偏移」降下来，它对观感影响最大。
- **想每页容纳更多字** → 减小「字体大小」「行间距」或边距。
- **改了参数没效果** → 确认改完后重新点了「生成预览」；界面上的改动不会自动重新渲染。
