# 照片作业的决策与回放实验

问题是同一份多页作业经过几轮检查后，能否更贴纸、少交出有明显问题的稿件，以及为此增加了多少次模型判断和工具调用。

## 比较方法

- A 组使用当前一次建稿结果。B 组从相同的稿件、纸张、字体和种子开始，宿主决策模型可以看稿、请求新证据、修改、选回旧版或停止。
- C 组沿用 B 的动作空间、预算和模型。开发任务结束后，根据实际决策和失败写一条有适用范围的策略，冻结策略和开发证据后再开封留出任务。
- 用同一版本的程序测量 A、B、C，记录输入与成稿指纹、草稿版本、节页、选中的版本、所有请求与失败尝试。每次修改须记下可检验的预期，随后再测。记录工具拒绝、无变化和主动放弃。
- 只用 Codex 宿主中的 Terra 或 Luna 做决策，决策者只拿当前任务的要求和已请求的证据。独立验收者以匿名、乱序的图稿判断，允许“看不清”。执行者与验收者分开，可复用公开接口接入其他模型。
- 纸张按来源分组。同一张纸的裁图、同模板近似拍摄、同一作业的两页，分别标记关系。任务数、独立纸张来源数和页数分别报告。留出组包含不同模板的实拍纸和程序生成的新纸。公开仓库提供可再生成的纸张、作业、测量方法、匿名结果及原图指纹；本机提供的照片在本地回放。

## 从现有 MCP 指引提取的验收依据

| 用户关心的问题 | 可以核实的证据 | 判定时容易混淆的地方 |
| --- | --- | --- |
| 仍在原纸上书写吗 | 对照建稿使用的纸张、photo 模式与最终导出选用的草稿版本 | 参考线叠图是诊断图，交付时看真实合成稿 |
| 从第一行到末行都贴纸吗 | 在原图上量印刷横线的位置，按当地行距归一化偏差；分开报告不同高度的结果 | 纸上的字样、阴影、参考线本身都可能使自动检测误判。只靠“最近一条线”也会漏掉整行偏移 |
| 数字、单位、上下标仍看得清吗 | 完整原文、排版位置、同一倍率的公式和邻行裁图 | 合法的下标可以低于同行。遇到分母与邻行靠得太近时须看实际墨迹 |
| 字迹符合这张照片的焦点和浓淡吗 | 对照同一高度、同一位置的纸纹和印线，保留全页与局部 | 像素对比度或边缘宽度是线索。视觉验收者单独记录观感与原因为何 |
| 能否交付这一版 | 草稿、修订号、节页和最终文件互相对应；写下未能核实的要求 | “看过工具返回”与“人确认了成稿”须分开记录 |

依据见 [MCP 排版与检查指南](../../tool-design.md)。判断只能引用本次读到的证据。模型的判断单独标记来源，人工意见须来自实际参与评审的人。

## 指标与判读

以成对任务为单位列 A→B 和 B→C 的结果，同时列出恶化和持平。客观指标包括相对行距的基线偏差、可测字形覆盖率和页数/内容保留。视觉指标包括所交付成稿被独立评审判为需要返工或证据不足的次数，以及给出理由的具体位置。严重错放指决策者接受交付而独立验收确认存在严重问题，两者都要有可核查记录。时间、工具调用、模型决策和人工返工分别记账；无人类用户计时时仅报告可测代理指标。

另记录规则可以发现、模型可以发现及两者判断冲突的案例。用相同复核名额比较按数值偏差挑样和按分歧挑样的结果。小样本仅用于验证可行性，按题逐一解释结果，不将一个模板的多个字或页面作为独立用户。
