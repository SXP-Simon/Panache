# 常见问题

## 为什么只显示第一页？

工作台可以只生成首页预览。打开「预览全部页面」并重新生成，再使用翻页按钮。若只是看不到页尾，先点「适合页面」。

## 为什么应用颜色变了，纸还是白的？

主色与辅助色分别影响导航、按钮和参数控件。要改变作品本身，请在「纸张」更换纸样或背景，在「笔迹」调整墨色。

## 可以离线使用吗？

桌面版自带 Rust 引擎，移动原生客户端通过随包引擎生成。浏览器工作台需要连接部署的 Rust 服务；本项目官网提供说明和样例。

## 扫描 PDF 可以直接提取手写文字吗？

导入效果取决于 PDF 能否提取文字。只有照片的页面可以作为纸张背景，再把正文粘贴到文字区。
