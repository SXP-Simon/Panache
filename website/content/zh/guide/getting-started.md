# 写下第一页

从[下载页](https://github.com/SXP-Simon/Panache/releases/latest)选与你的系统和处理器匹配的安装包。桌面客户端自带字体与渲染引擎，可以离线书写。

1. 打开「文字」，输入一小段话，或用「导入文档」读入 TXT、DOCX、PDF、RTF。
2. 在「字体排版」选择手写字体。先用两三行包含标点的文字试写，方便看出字距和笔锋。
3. 在「纸张」选空白、横线、方格或点阵。调整上下左右边距，给落款留一点空间。
4. 点「生成预览」。要看整篇，打开「预览全部页面」，再翻到末页检查结尾。
5. 保存当前页图片，或把全部页面导出为 PDF 或图片 ZIP。

在手机上，从分段工作台切换这些工具。收起键盘后即可看到底部导航和导出操作。
