# 预览、精修与导出

调字体时可以先预览第一页。「即时预览」会在文字或参数变动后刷新；准备导出时打开「预览全部页面」，逐页检查换行与边距。缩放之后，点「适合页面」看整张纸。

若只有个别字的位置不合适，进入「精细编辑」点选或圈选字符，可移动、改笔迹，或拉四角调整透视。手机可以全屏精修。

「保存当前图片」适合分享单页。整份手稿用 PDF 保留页序，或选图片 ZIP 取得每一页的 PNG。

在「纸张」中打开「透明 PNG（仅保留墨迹）」并刷新预览，即可保存去掉底纸、格线和横线的单页 PNG，也可用图片 ZIP 导出全部透明页面。PDF 保留原底纸。

### 底纸拍摄设备

使用照片作底纸时，PNG 及图片 ZIP 的每页会保留原图可读取的制造商、设备及镜头型号、ISO、焦距、光圈和曝光时间。PDF 在文档属性的「主题」中记录同样的信息。GPS、拍摄时间、序列号和缩略图均不复制。

打开「纸张 → 底纸拍摄设备」可补录制造商、设备型号、镜头型号和 ISO。名称使用设备标注的 ASCII 拼写，ISO 范围为 1–65535。原图有值的字段优先；补录项会在图片的 EXIF 描述和 PDF 主题中列出。没有原始信息和补录值时，导出文件不添加相机记录。

移动端缩图时，JPEG、PNG 和 WebP 会从图片中单独提取 EXIF 块。其他封装超过 64 MiB 时，在文件前 16 MiB 查找设备信息。

MCP 可用 `describe_controls` 查询 `camera` 组，再用 `tune_handwriting` 提交变动字段。例如 `changes={"camera_model":"Pixel 8","camera_iso":200}`。将字段设为 `null` 可清除补录。仅修改相机信息会保留当前笔迹精修。
