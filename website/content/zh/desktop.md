# 下载与离线使用

从 [GitHub 官方发布页](https://github.com/SXP-Simon/Panache/releases/latest)下载最新正式版。如果 GitHub 打不开，或下载总是中断，可以直接打开 [Panache 备用下载页（第三方 GH-Proxy）](https://gh-proxy.com/https://github.com/SXP-Simon/Panache/releases)，无需登录。

在 `SXP-Simon/Panache` 的最新正式版下，按设备选择文件。以 `.json` 结尾的是校验信息。

| 你的设备 | 安装包文件名结尾 |
| --- | --- |
| Windows 电脑（Intel 或 AMD，64 位） | `windows-x64.zip` |
| Mac（M 系列芯片） | `macos-arm64.zip` |
| Linux 电脑（Intel 或 AMD，64 位） | `linux-x64.tar.gz` |
| 大多数安卓手机 | `android-arm64-v8a.apk` |
| x86_64 安卓设备或模拟器 | `android-x86_64.apk` |

## 安装后

桌面包内有应用、字体和 Rust 引擎。完整解压后从应用入口启动，移动程序时保留整个目录。macOS 包使用 ad-hoc 签名，首次打开可能需要在系统隐私与安全性设置中允许。

在「关于与反馈」查看版本。更新方式随平台而异，详见[客户端更新说明](https://github.com/SXP-Simon/Panache/blob/main/docs/app-updates.md)。
