# Download and work offline

Download the latest stable version from [GitHub Releases](https://github.com/SXP-Simon/Panache/releases/latest). If GitHub is unreachable or your download keeps stopping, open the [Panache download mirror (third-party GH-Proxy)](https://gh-proxy.com/https://github.com/SXP-Simon/Panache/releases). You can download without signing in.

Under the latest stable release of `SXP-Simon/Panache`, choose the file for your device. Files ending in `.json` contain verification information.

| Your device | Package filename ends in |
| --- | --- |
| Windows PC (64-bit Intel or AMD) | `windows-x64.zip` |
| Mac with Apple silicon | `macos-arm64.zip` |
| Linux PC (64-bit Intel or AMD) | `linux-x64.tar.gz` |
| Most Android phones | `android-arm64-v8a.apk` |
| x86_64 Android device or emulator | `android-x86_64.apk` |

## After installation

Desktop packages contain the client, fonts and Rust engine. Extract the full package and keep the directory together when moving it. macOS packages are ad-hoc signed and may require approval in Privacy & Security on first launch.

Find the installed version under About and feedback. See the [update guide](https://github.com/SXP-Simon/Panache/blob/main/docs/app-updates.md) for platform-specific behaviour.
