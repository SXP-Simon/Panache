# Packages and source versions

Every stable release includes `Flutter-source.json`, linking its version, source commit and successful checks. The accompanying package JSON records SHA-256 for download verification.

Desktop and release-signed Android packages are built from the same commit. Open the [release history](https://github.com/SXP-Simon/Panache/releases), select a version and choose the package for your system and processor under Assets. See the [release process](https://github.com/SXP-Simon/Panache/blob/main/docs/release.md) for details.
