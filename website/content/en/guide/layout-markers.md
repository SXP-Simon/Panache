# Page breaks, signatures and maths

Put `---` on a line by itself to start a new page. Begin a line with `>>>` to right-align a date or signature.

```text
The end of the first poem
>>> November
---
The start of the second poem
```

Use LaTeX for fractions, radicals and matrices. The homework layout indents continuation lines and prefers relation symbols when breaking long equations. See the [math reference](https://github.com/SXP-Simon/Panache/blob/main/docs/math-support.md) for syntax and examples.
