# Write your first page

Choose a package for your system and processor from the [downloads](https://github.com/SXP-Simon/Panache/releases/latest). Desktop clients include fonts and the rendering engine and work offline.

1. Enter a few lines in Text or import a TXT, DOCX, PDF or RTF document.
2. Pick a handwriting font. Try a sentence with punctuation to judge spacing and stroke shape.
3. Choose blank, ruled, grid or dotted paper. Leave space around the text and at the foot of the page.
4. Generate a preview. Enable all-page preview and check the last page for the end of your text.
5. Save the current page as PNG or export the document as PDF or an image ZIP.

On a phone, use the workbench sections. Dismiss the keyboard to reveal bottom navigation and export actions.
